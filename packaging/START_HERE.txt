LocalPhraser — unsigned experimental Windows build

This is a development preview, not a stable release. Keep the entire folder together.

1. Run the preview installer, or extract the ZIP to a permanent folder.
   Keep the portable folder together; do not run the app from inside the ZIP.
2. Open LocalPhraser.exe. Windows may identify this unsigned app as unrecognized.
3. A new profile downloads base.en automatically in Settings. This first setup needs internet.
   Wait for "Speech model ready." No account or API key is needed. You can Cancel;
   retry with Download speech model. Later launches do not automatically retry.
   Already have models? Cancel, select their directory in Settings, then Save.
4. Place the cursor in a text field, hold CapsLock, speak, then release it.
   Save is needed only if you changed settings; the default model works as soon as installed.
5. Home and Settings are in the taskbar workspace. Theme changes apply immediately;
   Save applies other settings and keeps the page open. Minimize keeps the taskbar button;
   Close leaves background dictation available. Reopen the EXE to restore it. Use Quit to exit.

Raw mode is the default. Experimental Polished mode needs its own model download and
uses more memory and processing time. Try Raw first, then compare both modes.
Polished keeps the original in Latest transcript's Raw transcription tab.

After model installation, dictation operates locally without internet. Audio is never saved.
Transcript history is saved locally by default, without application-level encryption. Home
provides delete/clear controls; Settings can stop saving new entries. Latest transcript also
stays in memory. Explicit Copy changes the clipboard. Settings, models and history are
preserved when the app is uninstalled.
Check important text before sending it. Unverified fields, changed focus, and selected text
use manual-copy recovery to avoid inserting or overwriting in the wrong place.

Launch upon startup is off by default. Enable it in Settings only after choosing a permanent
application location. Disable it before moving or deleting that folder. It applies to the
current configuration and Windows user; no administrator access is required.
The installer adds a Start menu shortcut. Uninstall through Windows Installed apps;
settings and downloaded models are preserved. Quit from the tray before upgrading/removing.

Cancel download stops that installation and cleans its identified temporary files. Installed
models stay available. Retry after cancellation finishes. If cleanup fails, do not delete
unrelated files: consult the troubleshooting guide.
